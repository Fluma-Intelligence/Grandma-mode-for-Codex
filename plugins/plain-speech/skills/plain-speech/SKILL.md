---
name: plain-speech
description: Help users open or use the Grandma Mode card for a plain-language explanation of a Codex reply, a quick diagram, or a short follow-up.
---

Direct users to **Grandma Mode** in the current Codex Desktop chat's sidebar. Pick **Rewrite latest reply**, **Choose another reply**, or expand the original and select a passage. Users can also paste a report.

Explain that the three tabs use the same reply or passage. **In a few words** gives a short explanation. **Show me a diagram** asks for a visual only when the user requests one. **Ask little Codex** offers a simpler explanation, next steps, more detail, and a direct answer on whether something is fixed.

Let the user click the card's generation controls. Opening the card or switching tabs does not start a model request. The original stays folded until the user opens it. If asked to explain something directly in chat, use the source's language, everyday words, and the original facts, conditions, and uncertainty.

Use the gear for themes, character sizes, and importing a `.grandma-pet.json` file. To make a new character pack, use the bundled `grandma-pet` skill.
